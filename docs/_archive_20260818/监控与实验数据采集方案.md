## 1. 目标与设计原则

### 1.1 目标

为课题提供**可追溯、可量化、可对比**的实验数据支撑，满足《研究推进方案》7.3 节全部性能指标验收标准，并支撑消融实验与论文图表产出。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **零侵入框架** | 全部监控通过 Middleware 链与埋点函数实现，不修改 AgentScope / ReMe 源码 |
| **三层覆盖** | 框架层（自动）→ 记忆层（半自动）→ 调度层（自定义），数据无死角 |
| **一码两用** | 同一份数据既用于监控可视化，又用于实验统计分析 |
| **可复现** | 每次实验记录完整配置（版本、参数、种子），保证实验可复现 |
| **最小开销** | 埋点采用异步写盘 + 批量落盘，不影响调度链路性能 |

**采集能力对比**：

| 层 | 覆盖范围 | 实现方式 | 改动量 |
|----|----------|----------|--------|
| ① 框架层 | 回复/模型/工具全链路 | `TracingMiddleware()` 一行挂载 | 零 |

## 3. 第 1 层：框架内置 Tracing（OpenTelemetry）

### 3.1 接入方式

AgentScope 2.0.6 内置 `TracingMiddleware`（`agentscope/middleware/_tracing/_trace.py`），基于 OpenTelemetry 标准，挂载即采集：

```python
import agentscope
from agentscope.agent import Agent
from agentscope.middleware import (
    TracingMiddleware,
    ReMeMiddleware,
)

# 1. 初始化 OpenTelemetry（导出到本地文件，或 Studio / Jaeger）
agentscope.setup_tracing(
    service_name="srtp-memory-scheduling",
    trace_export_path="./data/traces",   # 本地导出目录
)

# 2. 挂载 Tracing 中间件（链首，覆盖全链路）
agent = Agent(
    name="main_agent",
    model=model,
    middlewares=[
        TracingMiddleware(),   # ← 全链路追踪
        ReMeMiddleware(
            workspace_dir="./data/reme/main",
            parameters=ReMeMiddleware.Parameters(mode="both"),
        ),
    ],
)
```

> 说明：`setup_tracing` 为示意 API，实际以 `agentscope.middleware._tracing` 暴露的初始化函数为准。核心点是：**只要初始化了 OTel TracerProvider，`TracingMiddleware` 即自动生效**（其内部 `_check_tracing_enabled()` 检测到 SDK 后开始埋点，未初始化时零开销短路）。

### 3.2 自动采集的 Span 与指标

`TracingMiddleware` 覆盖三类生命周期（`on_reply` / `on_model_call` / `on_tool_call`），每类生成独立 Span：

| Span 类型 | 触发时机 | 自动采集的核心字段 |
|-----------|----------|-------------------|
| **Agent 回复** | 每次 `agent()` 调用 | session_id、reply_id、输入/输出内容、耗时、状态（OK/ERROR） |
| **LLM 调用** | 每次模型调用 | prompt、response、**input_tokens / output_tokens**、耗时、模型名 |
| **工具执行** | 每次工具调用 | 工具名、入参、出参、是否外部执行 |

### 3.3 与实验指标的关系

| 验收指标 | 数据来源（第 1 层） |
|----------|---------------------|
| 平均响应时间 < 3s | Agent 回复 Span 的 `duration` |
| Token 消耗降低 ≥ 30% | LLM 调用 Span 的 `input_tokens + output_tokens` 求和 |
| 任务完成率 ≥ 90% | Agent 回复 Span 的 `status`（OK 视为成功） |

## 4. 第 2 层：ReMe 记忆层监控

### 4.1 设计：包装 `_run_job`

ReMe 的读写都收敛到 `ReMeMiddleware._run_job()`（唯一 Job 入口），在此处包一层计时与记录，即可覆盖 `auto_memory`（写入）与 `search`（检索）全部调用：

```python
# memory_monitor.py
import time
import json
from typing import Any


class ReMeMonitor:
    """ReMe Job 调用监控：记录每次 auto_memory / search 的入参与耗时"""

    def __init__(self, log_path: str = "./data/metrics/reme_jobs.jsonl"):
        self.log_path = log_path
        self._buffer: list[dict] = []

    def record_job(self, name: str, kwargs: dict, result: Any,
                   duration_ms: float) -> None:
        """记录一次 ReMe Job 调用"""
        entry = {
            "event": "reme_job",
            "job": name,                       # auto_memory / search
            "timestamp": time.time(),
            "duration_ms": round(duration_ms, 3),
            # 检索类记录 query 与 limit；写入类只记录消息条数（避免重复存内容）
            "params": self._safe_params(name, kwargs),
            "result_summary": self._summarize(name, result),
        }
        self._buffer.append(entry)
        if len(self._buffer) >= 50:            # 批量落盘，控制 I/O
            self.flush()

    def _safe_params(self, name: str, kwargs: dict) -> dict:
        if name == "search":
            return {"query": kwargs.get("query"), "limit": kwargs.get("limit")}
        if name == "auto_memory":
            msgs = kwargs.get("messages", [])
            return {"message_count": len(msgs)}
        return {k: str(v)[:200] for k, v in kwargs.items()}

    def _summarize(self, name: str, result: Any) -> dict:
        if name == "search":
            texts = _extract_memory_texts(getattr(result, "metadata", {}))
            return {"hit_count": len(texts)}
        return {"success": getattr(result, "success", True)}

    def flush(self) -> None:
        if not self._buffer:
            return
        with open(self.log_path, "a", encoding="utf-8") as f:
            for e in self._buffer:
                f.write(json.dumps(e, ensure_ascii=False) + "\n")
        self._buffer.clear()
```

### 4.2 包装进调度中间件

```python
class MemorySchedulingMiddleware(MiddlewareBase):
    def __init__(self, reme_middleware, monitor: ReMeMonitor, ...):
        self._reme = reme_middleware
        self._monitor = monitor

    async def _run_job(self, name: str, **kwargs):
        """包装 ReMe Job：调用前计时，调用后记录"""
        start = time.perf_counter()
        resp = await self._reme._run_job(name, **kwargs)
        self._monitor.record_job(
            name, kwargs, resp,
            (time.perf_counter() - start) * 1000,
        )
        return resp
```

### 4.3 采集的记忆层指标

| 指标 | 定义 | 用途 |
|------|------|------|
| `search 命中条数` | 每次检索返回的记忆数 | 检索有效性 |
| `auto_memory 写入条数` | 每次写入的消息数 | 记忆增长速率 |
| `记忆检索耗时` | search Job 耗时 | 检索性能 |
| `记忆写入耗时` | auto_memory Job 耗时 | 写入开销（异步，不影响回复） |

## 5. 第 3 层：调度层自定义埋点（核心）

### 5.1 完整埋点示例

每个调度决策记录一条结构化日志，涵盖四维得分、权重、动作选择与延迟：

```python
# scheduling_middleware.py（核心埋点）
import time
import json


class MemorySchedulingMiddleware(MiddlewareBase):
    """记忆调度中间件：四维注意力 + 混合权重 + 动作选择（含全量埋点）"""

    def __init__(
        self,
        reme_middleware,
        embed_model,
        llm_client,
        threshold: float = 0.6,
        max_shared: int = 10,
        log_path: str = "./data/metrics/schedule.jsonl",
        task_tag: str = None,          # 当前任务标签（任务注意力用）
    ):
        self._reme = reme_middleware
        self.scorer = MultiHeadAttentionMemoryScorer()
        self.weights = HybridWeightCalculator(llm_client, embed_model)
        self.selector = ActionSelector(threshold, max_shared)
        self._log_path = log_path
        self._task_tag = task_tag
        self._buffer: list[dict] = []

    async def on_reply(self, agent, input_kwargs, next_handler):
        inputs = input_kwargs.get("inputs")
        query = _extract_query_text(inputs)
        if query:
            # ① 候选召回（调用包装后的 ReMe search，同时写入第 2 层监控）
            candidates = await self._search_candidates(query, top_k=50)

            # ② 调度决策（逐段计时，记录每个中间量）
            t0 = time.perf_counter()
            query_emb = self.embed_model.encode(query).tolist()

            # ③ LLM 先验 + 可学习权重的混合权重
            t1 = time.perf_counter()
            weights = self.weights.calculate(query, self._bookmark_context())

            # ④ 四维注意力打分
            t2 = time.perf_counter()
            scored = [
                self.scorer.score(query_emb, m, time.time(), self._task_tag)
                for m in candidates
            ]

            # ⑤ 动作选择
            t3 = time.perf_counter()
            result = self.selector.select(scored)

            # ⑥ 核心埋点：记录一条完整调度记录
            self._log_schedule({
                "event": "schedule",
                "session_id": agent.state.session_id,
                "agent": agent.name,
                "timestamp": time.time(),
                "query": query,
                "task_tag": self._task_tag,
                "candidate_count": len(candidates),
                "weights": weights,                     # 四维权重快照
                "score_stats": self._score_summary(scored),  # 得分统计
                "kept_count": len(result["kept"]),
                "discarded_count": len(result["discarded"]),
                "latency_ms": {
                    "embedding": (t1 - t0) * 1000,
                    "weights": (t2 - t1) * 1000,
                    "scoring": (t3 - t2) * 1000,
                    "total": (t3 - t0) * 1000,
                },
            })

            # ⑦ 保留条目写入共享池（供副线 Agent 检索）
            shared_pool = SharedMemoryPool(result["kept"])
            self._shared_pool = shared_pool

        async for item in next_handler(**input_kwargs):
            yield item

    def _score_summary(self, scored: list) -> dict:
        """压缩得分统计：均值/最大/最小/分位数（避免日志过大）"""
        finals = [m["score"]["final"] for m in scored]
        if not finals:
            return {}
        import statistics
        return {
            "mean": round(statistics.mean(finals), 4),
            "max": round(max(finals), 4),
            "min": round(min(finals), 4),
            "p50": round(statistics.median(finals), 4),
        }

    def _log_schedule(self, entry: dict) -> None:
        self._buffer.append(entry)
        if len(self._buffer) >= 20:
            self._flush()

    def _flush(self) -> None:
        with open(self._log_path, "a", encoding="utf-8") as f:
            for e in self._buffer:
                f.write(json.dumps(e, ensure_ascii=False) + "\n")
        self._buffer.clear()
```

### 5.2 埋点字段与科研价值

| 字段 | 定义 | 科研用途 |
|------|------|----------|
| `candidate_count` | 候选记忆数（top_k=50） | 召回规模 |
| `weights` | 四维权重（LLM先验+可学习混合） | **权重动态性分析**（不同场景权重如何变化） |
| `score_stats` | 得分均值/最大/最小/中位数 | 记忆重要性分布 |
| `kept_count` / `discarded_count` | 保留/丢弃数 | **记忆池压缩比**（验收指标 ≤ 0.3） |
| `latency_ms.*` | 各阶段耗时 | **调度决策延迟**（验收指标 < 200ms） |
| `task_tag` | 当前任务标签 | 任务注意力相关性验证 |

## 6. 指标字典

### 6.1 指标总表（对齐《研究推进方案》7.3 验收标准）

| 验收指标 | 目标值 | 对应采集指标 | 采集层 | 单位 |
|----------|--------|-------------|--------|------|
| 记忆召回准确率 | ≥85%（提升≥15%） | `schedule.kept` 集合 vs 人工标注 | ③ | % |
| 任务完成率 | ≥90%（提升≥10%） | Tracing Agent span status | ① | % |

| Token 消耗降低率 | ≥30% | Tracing LLM span tokens 求和 | ① | tokens |
| 记忆池压缩比 | ≤0.3 | `schedule.kept / candidates` | ③ | 比率 |

### 6.2 全量指标清单（含辅助分析指标）

**时间类指标**

| 指标名 | 定义 | 采集点 |

| `llm_call_time` | 单次 LLM 调用耗时 | ① model span |

**成本类指标**

| 指标名 | 定义 | 采集点 |
|--------|------|--------|
| `input_tokens` | 输入 Token 数 | ① model span |
| `output_tokens` | 输出 Token 数 | ① model span |
| `total_tokens` | 单次回复 Token 总和 | ① 汇总 |
| `llm_call_count` | 单次回复的 LLM 调用次数 | ① 汇总 |
| `memory_pool_size` | 完整池记忆条目数 | ② workspace 文件统计 |

**质量类指标**

| 指标名 | 定义 | 采集点 |
|--------|------|--------|
| `recall_accuracy` | 召回准确率（人工标注比对） | ③ + 离线标注 |

**调度分析类指标（课题特色）**

| 指标名 | 定义 | 采集点 |
|--------|------|--------|
| `weights.time/semantic/frequency/task` | 四维注意力权重快照 | ③ |
| `score.time/semantic/frequency/task` | 单条记忆四维得分 | ③ |
| `kept/discarded_count` | 保留/丢弃数量 | ③ |
| `compression_ratio` | 压缩比 = kept/candidates | ③ 计算 |
| `candidate_count` | 候选规模 | ③ |
| `weight_delta` | 权重在线更新量 | ③ 相邻记录差值 |

### 8.2 核心统计脚本骨架（compute_metrics.py）

```python
import json
import pandas as pd


def load_schedule_log(path: str) -> pd.DataFrame:
    """读取调度日志 JSONL → DataFrame"""
    rows = []
    with open(path, "r", encoding="utf-8") as f:
        for line in f:
            rows.append(json.loads(line))
    return pd.DataFrame(rows)


def compute_core_metrics(df: pd.DataFrame) -> dict:
    """计算 6 项核心验收指标"""
    metrics = {}

    # 1. 记忆池压缩比（验收 ≤ 0.3）
    df["compression_ratio"] = df["kept_count"] / df["candidate_count"]
    metrics["compression_ratio"] = df["compression_ratio"].mean()

    # 2. 调度决策延迟（验收 < 200ms）
    metrics["schedule_delay_ms"] = df["latency_ms"].apply(
        lambda x: x["total"] if x else None
    ).mean()

    # 3. Token 消耗（从 Tracing 日志汇总，此处为接口示意）
    #    token_df = load_trace_log(...); metrics["total_tokens"] = ...

    # 4. 召回准确率（需与人工标注集合比对）
    #    metrics["recall_accuracy"] = compute_recall(df, labeled_set)

    return metrics


def compare_groups(manifest: str) -> pd.DataFrame:
    """对比 baseline 组与 ours 组的所有指标"""
    runs = pd.read_csv(manifest)
    rows = []
    for _, run in runs.iterrows():
        df = load_schedule_log(f"./data/runs/{run['run_id']}/schedule.jsonl")
        m = compute_core_metrics(df)
        m.update({"run_id": run["run_id"], "group": run["实验组"]})
        rows.append(m)
    result = pd.DataFrame(rows)
    # 输出对比表：每行一组实验，每列一项指标
    return result
```
