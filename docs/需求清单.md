---

## 使用说明

- **编号规则**：`REQ-<类><序号>`
  - `1xx` 智能体层 / `2xx` 接口层 / `3xx` 记忆层 / `4xx` 协调层 / `5xx` 端到端工作流 / `6xx` 实验验证 / `7xx` 工程约束
- **优先级**：
  - `P0` = 第二阶段必须（2026.08-10 核心算法 + 原型开发）
  - `P1` = 第三阶段（2026.11-2027.01 系统集成与功能完善）
  - `P2` = 第四阶段（2027.02-03 实验验证与性能优化）
- **来源**：标注课题材料章节（如 `2.1`、`创新点1`、`拟解决问题(1)`、`表2`、`技术路线`），保证每条需求可追溯到原始申报材料。
- **修改方式**：直接编辑本表格的"需求/优先级/说明"列；增删需求时保持编号连续性，或在对应类末尾追加序号。
