## 八、关键方法论（踩过的坑，勿重犯）

1. **指标不动时，先怀疑实验设置，再怀疑算法**（三次验证：D-036 公式值域 / D-040 源池内容 / D-043 评估设置）
2. **评估必须"约束真实 + 指标对口"**：`K ≈ |relevant|`；排序器用 MRR/nDCG
3. **注入/改进不能污染实验变量**（D-028：`source_topk` 是变量，改它破坏了 G2 对照）
4. **数据集注入项不能与既有内容语义重叠**（D-029/D-040：否则规则先作用于重叠项）
5. **"指标变好"先验证因果链**（D-036：否则会把"废掉先验"当成"改进有效"）
6. **共享样式表不用 `.legend`/`.node` 这类通用类名**（撞名导致控制台图例被盖）
7. **`TaskOutput(block=true)` 长等会切断后台任务**；用 `sleep` + 查文件轮询
