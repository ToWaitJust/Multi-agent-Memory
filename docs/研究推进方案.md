# 基于注意力引导和LLMs可学习权重的多智能体记忆共享调度方法研究
## 研究推进方案

---

## 一、项目概述

### 1.1 项目定位

本项目为福州大学本科生科研训练计划（SRTP）创新训练项目，聚焦于大模型驱动的多智能体协作场景下的记忆共享调度问题。通过引入注意力机制与LLMs可学习权重，构建读写分离的"双池"记忆架构，实现主线任务聚焦与分支进程隔离，有效提升复杂场景下多智能体系统的协作效率与响应质量。

### 1.2 核心研究目标

| 目标层级 | 具体内容 | 验收标准 |
|----------|----------|----------|
| **理论目标** | 构建多智能体记忆共享调度问题的形式化模型 | 形成完整的理论框架，涵盖记忆表示、权重获取、协同机制 |
| **算法目标** | 设计融合多维属性的注意力引导机制与混合权重模型 | 四维注意力打分体系 + LLM先验/可学习权重混合调度 |
| **系统目标** | 开发主副线协同的多智能体对话系统原型 | 多窗口交互 + 书签定位 + 双池记忆架构 |
| **验证目标** | 通过基准对比实验验证方法有效性 | 在准确性、效率、经济性、资源利用率四维度显著优于基线 |
| **成果目标** | 发表学术论文1篇 + 产出可运行的系统原型 | 论文投稿 + 系统开源/演示 |

### 1.3 关键创新点回顾

1. **交互范式创新**：主副线协同与状态隔离机制，物理隔绝上下文污染
2. **决策评价创新**：四维注意力引导机制（时间/语义/频率/任务）
3. **数据架构创新**：读写分离的"双池"记忆拓扑架构

## 七、质量保障与验收标准

### 7.1 代码质量保障

- **代码规范**：遵循PEP8（Python）/ ESLint（前端）规范
- **单元测试**：核心模块代码覆盖率 ≥ 70%
- **代码审查**：重要功能合并前必须经过至少一人review
- **持续集成**：配置CI/CD，自动运行测试

### 7.2 功能验收标准

| 模块 | 验收标准 | 测试方法 |
|------|----------|----------|
| **记忆层** | 1. 支持记忆的增删改查<br>2. 语义检索准确率 ≥ 90%<br>3. 单次检索延迟 < 100ms | 功能测试 + 性能测试 |
| **注意力机制** | 1. 四维注意力打分正常<br>2. 能有效区分重要/不重要记忆<br>3. 计算延迟 < 50ms/条 | 单元测试 + 对比实验 |
| **权重模块** | 1. LLM权重生成稳定<br>2. 可学习权重训练收敛<br>3. 混合权重计算正确 | 功能测试 + 收敛性测试 |
| **智能体层** | 1. 主线/副线智能体正常交互<br>2. 消息通信可靠<br>3. 状态同步正确 | 集成测试 + 压力测试 |
| **前端界面** | 1. 多窗口正常工作<br>2. 书签定位功能正常<br>3. 交互流畅无明显卡顿 | 用户测试 + 性能测试 |
| **完整系统** | 1. 端到端流程跑通<br>2. 功能完整可用<br>3. 用户体验良好 | 系统测试 + 用户验收 |
